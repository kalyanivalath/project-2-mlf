# project-2-mlf
## Data Organization

For this project, we organized the data into three groups based on the number of independent variables: 1D, 2D, and 3D. Each group contains three datasets with low (L), moderate (M), and high (H) noise. Each dataset contains 100 data points.

The original datasets are stored in the `Data` folder as CSV files. The columns are organized as follows:

- **1D:** Two columns containing x and y.
- **2D:** Three columns containing x1, x2, and y.
- **3D:** Four columns containing x1, x2, x3, and y.

We created three Python files (`regression_1d.py`, `regression_2d.py`, and `regression_3d.py`) to perform linear regression on each group of datasets.

The results are saved in `results_1d.csv`, `results_2d.csv`, and `results_3d.csv`. These files contain the fitted coefficients, standard errors, RSS, R², adjusted R², and RSE for each dataset.

All graphs generated by the programs are saved in the `figures` folder. These include scatter plots, predicted vs. actual plots, residual plots, and Q-Q plots used to analyze the regression performance.
